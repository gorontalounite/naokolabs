# Spesifikasi fullset untuk pilot

Status: BASELINE PILOT v0.3 — 11 Oktober 2026. Dibuat untuk menguji tarif dan kualitas; belum syarat layanan publik atau persetujuan harga komponen. Pengguna mengotorisasi penyusunan cakupan dan analisis biaya. Angka anchor pengguna tetap Rp350.000/1 konten, Rp1.250.000/5, Rp2.000.000/10 untuk fullset standar.

## Video standar

| Aspek | Cakupan pilot |
|---|---|
| Durasi | Maksimal 30 detik, target durasi dipilih sebelum approval |
| Output | Satu MP4, 1080×1920, 9:16, 30 fps |
| Naskah | Satu naskah original per konten, satu bahasa Indonesia; perkiraan 60–80 kata diuji timing sebelum approval |
| Rencana | Satu strategi singkat dan satu storyboard, maksimal 6 scene |
| Visual included | Hingga 6 visual stock/library berlisensi atau aset klien, reuse visual diperbolehkan |
| Animasi | Teks, shape, diagram dan transisi/template 2D standar |
| VO | Satu voice library yang lolos uji, satu bahasa, satu narasi final; tanpa cloning/avatar/lip-sync |
| Musik | Satu track library yang memenuhi hak penggunaan; mixing dan level audio diperiksa |
| Caption | Satu caption Bahasa Indonesia sesuai pesan/CTA yang disetujui |
| Subtitle | Satu gaya sederhana bila VO digunakan, diaktifkan saat brief dan termasuk produksi dasar pilot |
| Delivery | Preview, file final, caption dan riwayat versi; source editable/thumbnail/rasio tambahan di luar baseline |
| Persetujuan | Script/scene/aset/format sebelum produksi, artefak/caption final sebelum publikasi |

Batas kata bukan alasan memotong naskah yang disetujui. Bila audio tidak muat durasi, selesaikan opsi penyesuaian sebelum approval. PDF/CSV merupakan sumber; ekstraksi dan pemeriksaan dasar included, riset panjang/terjemahan besar dikutip terpisah sebelum checkout.

Fullset stock tidak mengandung shot AI premium tanpa batas. Jika memilih AI-generated, quote memiliki model, detik/gambar, jumlah kandidat internal, biaya dan output yang eksplisit. Dalam UI, bedakan 'Visual standar included' dari 'Footage AI tambahan'.

## Carousel standar

| Aspek | Cakupan pilot |
|---|---|
| Unit | Satu konten berisi maksimal 8 slide, bukan 8 konten |
| Output | JPG atau PNG, satu format 1080×1350 (4:5), urutan slide jelas |
| Copy | Satu alur pesan; heading singkat dan isi secukupnya, target total sekitar 200 kata |
| Visual | Hingga 6 visual stock/library atau aset klien; layout, ikon sederhana dan brand styling included |
| Perencanaan | Struktur slide, pesan/CTA dan visual binding disetujui sebelum desain final |
| Caption | Satu caption Bahasa Indonesia |
| Audio | VO/musik tidak termasuk dan tidak dikenai tarif pada carousel statis |
| Delivery | Preview seluruh slide, download set, caption; editable source di luar baseline |

Copy padat tidak dipaksakan ke slide untuk memenuhi batas. Diagram/ilustrasi khusus atau banyak data perlu quote kompleksitas. Carousel animasi/video adalah SKU lain.

## Jenis yang boleh masuk tarif standar setelah pilot lulus

Motion Graphic template, Explainer diagram sederhana, Whiteboard template, edit footage UGC milik klien, cinematic berbasis stock, illustration 2D berbasis aset siap pakai. Kesamaan label tidak menjamin kompleksitas standar.

UGC presenter AI, cinematic banyak shot AI, illustration/karakter custom, 3D/VFX dan jingle original memakai quote sampai pilot khusus menunjukkan biaya/kualitas yang layak. Katalog tetap dapat menampilkan jenis tersebut dengan status quote/request, tidak sebagai layanan instan yang belum tersedia.

## Paket dan perubahan komponen

Satu order 5/10 berisi jumlah konten tersebut, dibayar sekaligus, setiap item memiliki brief/naskah/approval sendiri. Tarif tier berlaku per komponen relevan. Pilot awal satu jenis/pricing profile per kelompok paket; mixing video/carousel/premium membutuhkan aturan yang disepakati. Kuantitas lain ditawarkan melalui kombinasi paket + satuan yang transparan, bukan harga non-monotonik atau output tambahan tanpa persetujuan.

Membeli naskah terpisah dan kemudian memakai naskah itu untuk video tidak dikenai penulisan naskah yang sama lagi. Alternatif script/hook dengan output baru adalah versi tambahan. Normalisasi pengucapan oleh TTS tidak mengubah isi/makna script yang disetujui.

## Revisi dan publikasi

Hak koreksi mengikuti tiga jenis dari pengguna: penempatan gambar/video, typo, pengucapan VO. Usulan operasi: feedback dikumpulkan per putaran, dua putaran awal, dalam 7 hari setelah delivery. Kesalahan produksi yang terverifikasi dan belum diperbaiki tetap tanggung jawab layanan; tidak berubah otomatis menjadi biaya tambahan karena kuota putaran habis. Jumlah/tenggat ini usulan, belum kebijakan publik.

Konsep/promo/durasi/voice/style/rasio baru setelah approval menjadi change request dengan harga sebelum eksekusi. Perubahan rencana sebelum approval dicatat terpisah; batas penulisan ulang konsep belum diputuskan.

File output + caption termasuk anchor fullset. Tarif posting/scheduling belum ditentukan dan tidak ditambahkan diam-diam. Dashboard menyediakan kemampuan posting sesuai izin platform. Native platform audio, durasi Story dan format akun harus diperiksa; file 30 detik tidak menjamin kompatibel pada seluruh kanal/akun.

## Kriteria lulus spesifikasi

Seluruh output sesuai brief/brand/sumber; durasi/ukuran/urutan benar; script dan fakta tidak berubah; teks terbaca di ponsel; pengucapan diperiksa dengan mendengarkan; tidak ada media salah/crop/blank; lisensi aset tercatat; versi dan approval cocok.
